Términos y Condiciones

UPlan – Herramienta independiente de gestión académica

Al crear una cuenta o utilizar la plataforma UPlan, aceptás expresamente los presentes Términos y Condiciones, así como nuestra Política de Privacidad, de conformidad con la legislación vigente en Costa Rica.

1. Descripción del Servicio

UPlan es una herramienta de gestión académica personal diseñada para estudiantes universitarios. La plataforma permite visualizar planes de estudio, generar horarios y calcular promedios ponderados.

Esta plataforma NO es un sistema oficial de la UCR. Es una herramienta independiente creada por un estudiante. La información mostrada es referencial y no sustituye los registros oficiales de la Universidad.

2. Datos Personales y Privacidad (Ley N.° 8968, Costa Rica)

De conformidad con la Ley de Protección de la Persona frente al Tratamiento de sus Datos Personales y su reglamento, te informamos lo siguiente:

  • Datos recolectados: Nombre de usuario (seudónimo), nombre completo (opcional) y carné estudiantil (opcional).
  • Finalidad: Los datos se utilizan EXCLUSIVAMENTE para autenticar tu cuenta, sincronizar tu progreso en la nube y personalizar tu experiencia visual.
  • No compartimos tus datos: Tu información NO se vende, transfiere ni comparte con terceros. Es de uso exclusivamente interno para el funcionamiento de la app.
  • Tus derechos ARCO: Tenés derecho a Acceder, Rectificar, Cancelar u Oponerte al uso de tus datos. Podés eliminar tu cuenta y todos tus datos permanentemente desde el menú de Perfil, o contactarnos vía la sección de "Feedback".

3. Publicidad y Financiamiento

Para financiar el mantenimiento de los servidores (Supabase), la plataforma podría mostrar anuncios de terceros (ej. Adsterra). Los anuncios son estáticos o nativos; NO usamos pop-ups ni formatos agresivos (jumpscares). Al usar la app sin bloqueador de anuncios, contribuís al sostenimiento del proyecto.

4. Limitación de Responsabilidad

La plataforma se ofrece "tal como está". No garantizamos la exactitud absoluta de los planes de estudio, ya que pueden variar según modificaciones oficiales de la UCR. El desarrollador (equipo Uplan) no es responsable por decisiones académicas tomadas con base únicamente en la información aquí mostrada.

Reglas de Convalidación

Nueva Convalidación

SQL necesario (ejecutar una sola vez en Supabase):

CREATE TABLE IF NOT EXISTS public.convalidaciones (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  carrera_origen text NOT NULL,
  codigo_origen text NOT NULL,
  carrera_destino text NOT NULL,
  codigo_destino text NOT NULL,
  created_at timestamptz DEFAULT now()
);
ALTER TABLE public.convalidaciones ENABLE ROW LEVEL SECURITY;
CREATE POLICY "admin_manage_conv" ON public.convalidaciones FOR ALL
  USING ((SELECT is_admin FROM profiles WHERE id = auth.uid()) = true)
  WITH CHECK ((SELECT is_admin FROM profiles WHERE id = auth.uid()) = true);
CREATE POLICY "public_read_conv" ON public.convalidaciones FOR SELECT USING (true);

SQL para ver todos los usuarios (ejecutar una sola vez):

-- Política de admin para leer todos los perfiles
CREATE POLICY "admin_read_all_profiles" ON public.profiles
  FOR SELECT USING (
    auth.uid() = id OR
    (SELECT is_admin FROM public.profiles WHERE id = auth.uid()) = true
  );
-- Política de admin para modificar catálogo
CREATE POLICY "admin_write_catalog" ON public.courses_catalog
  FOR ALL USING (
    (SELECT is_admin FROM public.profiles WHERE id = auth.uid()) = true
  ) WITH CHECK (
    (SELECT is_admin FROM public.profiles WHERE id = auth.uid()) = true
  );
-- Activar tu cuenta como admin (reemplazá el username)
UPDATE public.profiles SET is_admin = true WHERE username = 'DENGO1106';
